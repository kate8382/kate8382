## 🚀 Featured Projects

### 🛡️ [AURA: AI User Risk Assessment Framework](https://github.com/kate8382/AURA)
An open-source library of structured behavioral matrices, heuristics, and validation tooling designed to detect manipulation, deception, and grey-zone threats in human–AI interactions.
- **What it does:** Addresses the gap in static safety guardrails by focusing on psychological and tactical social engineering vectors (emotional pressure, false urgency, fake authority).
- **Tech Stack:** TypeScript, Node.js, AJV (JSON Schema Validation), Jest.
- **Licensing:** Apache 2.0 (code) & CC BY-NC 4.0 (public dataset).

### 📊 [Error Logger & Viewer](https://github.com/kate8382/error-logger-viewer)
A robust SPA migrated to **TypeScript** for collecting, grouping, analyzing, and visualizing client-side JavaScript errors in real-time.
- **Key Features:** Global error handlers (`window.onerror`, fetch interception), multi-language UI (`i18n`), interactive charts (Chart.js), and dual modes (Server: Express + LowDB / Demo: localStorage).
- **DevOps/Tooling:** Fully containerized with multi-stage Docker builds and Docker Compose (production/development profiles). Automated CI via GitHub Actions. Patched with `patch-package`.
- **Live Demo:** [Try it here](https://kate8382.github.io/error-logger-viewer/)

### 🎨 [WeCoded — Gender Equity (Frontend Art)](https://github.com/kate8382/wecoded-gender-art-2026)
An interactive, dependency-free frontend art performance visualizing gender equity in the workplace and the invisible burden of domestic labor through dynamic SVG scales and spatial audio.
- **Tech Highlights:** Modular plain JS, robust audio synchronization scheduling (`AudioDirector`), custom gravity/spiral physics animations (`Dropper`), and responsive CSS variable tokens.
- **Read the Story:** [On dev.to](https://dev.to/kate8382/the-invisible-scales-a-frontend-art-performance-on-gender-equity-1n0o) | 📺 [Watch on YouTube](https://youtu.be/eMlrY8YFxos)

### ⚡ [Frontend Starter](https://github.com/kate8382/frontend-starter)
A lightweight, fully accessible frontend boilerplate built with Vite, TypeScript, and BEM-style responsive CSS using `clamp()` fluid tokens.
- **Features:** Centralized API client, keyboard-accessible UI, and pre-configured Vitest environment optimized for Windows environments.
