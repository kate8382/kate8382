## 🚀 Featured Projects

#### 🛡️ [AURA: AI User Risk Assessment Framework](https://github.com/kate8382/AURA)
An open-source library of structured behavioral matrices, heuristics, and validation tooling designed to detect manipulation, deception, and grey-zone threats in human–AI interactions.
- **What it does:** Bridges the gap between static safety guardrails and fluid human psychology by targeting social engineering vectors (false urgency, fake authority, alibi manipulation).
- **Tech Stack:** TypeScript, Node.js, AJV (JSON Schema Validation), Jest, GitHub Actions.
- **Licensing:** Dual/Hybrid — BSL 1.1 (Code & Tooling) & CC BY-NC 4.0 (Dataset).

#### 🎵 [Custom Media Platform Showcase](https://github.com/kate8382/custom-media-platform-showcase)
A high-performance, responsive single-page web architecture designed for audio streaming, dynamic Bandcamp integration, and custom media showcases.
- **What it does:** Rebuilt from legacy WordPress code (320+ engineering hours with [David H. Watson](https://github.com/dEhiN)), featuring custom Node.js + FFmpeg CLI pipelines for automated asset transcoding, zero-dependency SPA routing, and responsive SCSS design.
- **Tech Stack:** Vanilla JS, Node.js, FFmpeg, Express, Vite, Vitest, Playwright.
- **Resources:** [YouTube Walkthrough](https://www.youtube.com/watch?v=R8rgODfEkXc)

#### 📊 [Error Logger & Viewer](https://github.com/kate8382/error-logger-viewer)
A robust SPA migrated to TypeScript for collecting, grouping, analyzing, and visualizing client-side JavaScript errors in real-time.
- **Key Features:** Global error handlers (`window.onerror`, fetch interception), multi-language UI (i18n), interactive charts (Chart.js), and Express/localStorage dual modes.
- **DevOps:** Fully containerized with multi-stage Docker builds, Docker Compose, and automated CI via GitHub Actions.

#### ⚡ [Frontend Starter](https://github.com/kate8382/frontend-starter)
A lightweight, accessible frontend boilerplate built with Vite, TypeScript, and BEM-style responsive CSS using `clamp()` fluid tokens and pre-configured Vitest environment.
- **Key Features:** Centralized API client, keyboard-accessible UI, and pre-configured Vitest environment optimized for Windows environments.

#### 🎨 [WeCoded — Gender Equity (Frontend Art)](https://github.com/kate8382/wecoded-gender-art-2026)
An interactive, dependency-free frontend art performance visualizing gender equity in the workplace through dynamic SVG scales and spatial audio.
- **Tech Stack:** Modular plain JS, robust audio synchronization scheduling (`AudioDirector`), custom gravity/spiral physics animations (`Dropper`), and responsive CSS variable tokens.
- **Resources:** [YouTube Walkthrough](https://www.youtube.com/watch?v=eMlrY8YFxos)
